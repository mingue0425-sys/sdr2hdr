Production differences between the two commits that matter to this audit are:

- `HDRConfiguration.swift`: d97 promotes `calibratedV4` and makes its exact
  production values available, including `sceneRelativeV4` and mastering
  headroom `5.308875`. The port leaves that declaration unchanged.
- `HDRProcessor.swift`: d97 contains the production output-lease lifetime,
  temporal generation, and completion-ordering behavior. The port keeps those
  mechanisms and adds diagnostic metadata around them.
- `SDRToHDR.metal`: d97 uses the configured `peakRatio` for the saturation
  transition and reconstructs NV12 temporal-estimator luminance from Y plus
  UV. Both production behaviors are preserved.
- `DisplayCapabilities.swift` and `HDRMetalView.swift`: d97 distinguishes an
  actively presenting EDR display from mere capability and refreshes the EDR
  color-space decision. The port keeps this boundary.
- `PlaybackController.swift`: d97 uses `copyPixelBuffer` and its current
  texture acquisition path. The port does not restore the older macOS 26
  pixel-buffer API path.
- `PlayerOptions.swift`: d97 defaults to and accepts `calibrated-v4`; the
  diagnostic options are additive.

The audited stage order is:

```text
SDR decoded linear Y
  → production toneExpand()
  → linear saturation/gamut handling
  → HDRCore EDR texture
  → presentation direct-EDR mapping
```

`processor.update(configuration:)` retains temporal and scene history while
advancing a generation guard that rejects late completions from the previous
configuration generation. Controlled A/B instead creates independent V2 and V4
processors, with separate temporal and scene state, for the same source
pixel buffer and timestamp.


The shoulder starts at `Y≈0.49891537` while low-mid is already fully active.

the signal. The overlap is a secondary contributor, not an explanation for the
low and ordinary midtone lift below the shoulder.

## 8. Scene Anchor Analysis

The d97 full-frame samples report `sceneShadowFloor=0.03125`,
`sceneShadowTop=0.05625`, and valid scene statistics for V4. V2 uses its
legacy fallback coordinates `0.01000/0.11250` with scene-relative control
disabled.

With the V4 anchors, the smooth transition is already `0.843750` at `Y=0.05`
and exactly `1.0` from `Y=0.06` through the ordinary midtone range. This makes
the narrow anchor band a conditioning factor for the broad low-mid expansion.
It is not a separate face heuristic and it was not changed in this work.

The DEBUG near-black bands are also implemented. One captured d97 test6
diagnostic frame reported approximately:

```text
input Y < 0.01: mean gain 0.97046
input Y < 0.02: mean gain 0.98880
input Y < 0.05: mean gain 1.00927
lifted pixel ratio: 0.26099
crushed pixel ratio: 0
```

This is useful evidence that the bands are observable, but it is one frame and
does not justify changing V4 shadow behavior.

## 9. Root Cause

### Root-cause ranking

1. **Generic diffuse-midtone over-expansion — confirmed at the full-frame and
   mathematical level.** The d97 controlled samples reproduce a positive V4
   low-mid contribution of `0.056409...0.060256` while V2 is zero. The scalar
   d97 expression predicts a stable approximately 20.6% gain after
   `Y≈0.05625`. Code: `Sources/HDRCore/Shaders/SDRToHDR.metal:163-168` and
   the observation-only breakdown at `:215-224`.
2. **Early shoulder overlap — confirmed as a co-contributor.** d97 V4 has
   `shoulderStart=0.49891537`; V2 is `0.51716954`. The shoulder adds on top of
   a low-mid term that is already fully active. Code:
   `Sources/HDRCore/Shaders/SDRToHDR.metal:140-165`.
3. **Narrow scene-relative shadow anchors — confirmed as conditioning.** The
   observed `0.03125/0.05625` band makes the low-mid transition complete before
   ordinary diffuse values. Code:
   `Sources/HDRCore/Shaders/SDRToHDR.metal:157-164`.
4. **Temporal, saturation, and presentation EDR — not supported as the primary
   cause by the available evidence.** Temporal adaptation stayed near
   `0.9618...0.9683` without a spike. Tone-expanded and core EDR luminance were
   equal within readback precision, and presentation mapping lowered the
   measured average in the representative d97 sample. Saturation changes the
   chroma path after tone expansion; no added luminance was observed.

### Decision

```text
GENERIC DIFFUSE-MIDTONE OVER-EXPANSION: CONFIRMED
FACE-SPECIFIC/SKIN-SPECIFIC ATTRIBUTION: NOT CONFIRMED
```

The generic diagnosis is strong enough to establish the processing-stage
cause. The requested claim that the visible face in `test6.mp4` is affected by
the same gain remains pending because the actual three-frame face ROI and
same-luminance non-skin control could not be collected after the source file
disappeared. No skin heuristic or face detector was added.

## 13. V6 Design Preconditions

No V6 algorithm or tone curve was implemented.

The next development step must first reproduce the generic ROI evidence on
three or more d97 `test6.mp4` face frames and matched non-skin midtone controls.
Then evaluate, independently and in a development-only path:

1. separation of the broad low-mid term from the narrow shadow-protection
   transition;
2. the overlap between the low-mid term and the early shoulder;
3. scene-anchor behavior when `shadowTop` is near the diffuse range;
4. temporal and histogram-distance behavior at verified scene cuts;
5. near-black gain and contrast preservation across all three bands.

These are mathematical preconditions for a later V6 design. They are not
parameter recommendations, and no production V4 value was changed here.
